# i18n

Every user-facing string goes through the catalog — English in the code is the lookup key.

- Catalogs live in `crates/ui-egui/src/i18n/<lang>.tsv` as `key<TAB>translation` rows.
  English needs no file — the key is the fallback, so missing rows never render blank.
- Look up with `t(key, lang)`; interpolate with `tf(key, lang, arg)` where the key carries
  `{0}` placeholders. Never concatenate translated fragments.
- `Lang` is `Auto` plus every supported language; `Auto` resolves from
  `<APP>_LANG`, `LC_ALL`, `LANG` — including the tricky mappings (`iw`→he, `in`→id,
  `no/nb/nn`→nb, `pt_BR`→Brazilian, `zh_TW/HK`→Traditional, other `zh`→Simplified).
- The picker lists **native** language names.
- RTL languages (ar/fa/he) flip the layout direction; absolute-positioned UIs mirror x.
- A CJK language draws with the **system's** CJK font — never bundle one (10 MB+).
- Tests: every catalog covers every key the code looks up; fallback/format/RTL have unit
  tests. Catalog rows the user edited win over any re-import — merge, don't overwrite.
